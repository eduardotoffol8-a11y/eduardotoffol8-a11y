## Engenharia de contexto para agentes

### [HyperContext — prompt caching e context pruning](https://github.com/eduardotoffol8-a11y/hypercontext)

Guia técnico e receitas reutilizáveis para reduzir recomputação de prefixos e
administrar o contexto de agentes. Inclui integração Anthropic Messages API,
diretrizes para Claude Code e Codex, critérios de adoção e testes de contrato.

- Cache nativo com prefixos estáveis e contabilização por provedor.
- Limpeza seletiva de resultados de ferramentas, com preservação de estado e recuperação de evidências.
- Arquivos `CLAUDE.md`, `AGENTS.md` e prompts de continuidade para incorporar a outros projetos.
- Protocolo de avaliação de custo, qualidade e retomada, distinguindo testes locais de medições reais.
